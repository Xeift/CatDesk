# Contributing

Thanks for contributing!

## Development

1. Fork and clone the repository.
2. Create a new branch with `git switch -c feat/your-feature`.
3. Make your changes.
4. Run `cargo fmt`.
5. Run `cargo test --release`.
6. Run `cargo build --release`.
7. Open a pull request.

## Code Style

Please follow the existing code style and run `cargo fmt` before committing.

## Commits

Use clear commit messages. We recommend Conventional Commits:

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` refactoring
- `test:` tests

## Pull Requests

Open pull requests directly to `main`.

## Issues

If you'd like to open an issue, feel free to do so.
